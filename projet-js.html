Présentation du projet

Ce projet avait pour objectif de créer un mini-site interactif pour mettre en pratique JavaScript : boutons cliquables, formulaires dynamiques et animations simples.

Malheureusement, je n’ai pas pu mettre en application JavaScript sur ce portfolio-ci car ce n’était pas demandé dans le projet principal.

Ce travail m’a permis de mieux comprendre les événements et la création de petites animations fonctionnelles.

Compétences développées

  • Événements JavaScript (click, input…)
  • Modification dynamique du contenu
  • Animations simples et gestion d’interactions utilisateur

Conclusion

Bien que je n’aie pas intégré JavaScript dans ce portfolio, ce projet m’a donné confiance dans mes capacités à créer des sites interactifs et à préparer des fonctionnalités avancées pour de futurs projets.
