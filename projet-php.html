Description

Ce projet est une application web permettant de gérer les ventes de jeux vidéo en France selon le type de jeu, l’année, et d’autres critères. Le backend est développé en PHP avec une base de données MySQL.

Compétences mises en œuvre

  • Conception de base de données MySQL
  • Requêtes SQL pour extraire et manipuler les données
  • Interface web dynamique en PHP
  • Présentation des résultats sous forme de tableaux et graphiques

Objectifs atteints

Ce projet m’a permis de comprendre comment combiner une base de données et une interface web pour créer une application complète et fonctionnelle.
